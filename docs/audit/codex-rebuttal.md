# Codex's rebuttal of Claude's gap list

Across both lists, the three most important items are opening balances (Claude 2.1/3.1; Codex Must fix 6), because they make the first month’s ledger, ageing, reminders and payment allocation wrong; safe email sending (Claude 2.2; Codex Must fix 1), because the interface can imply invoices were sent when the console driver only logs them; and Tally import compatibility (Claude 2.3; Codex Must fix 4), because an export that cannot be imported or mapped correctly blocks the accountant’s workflow. I would drop Claude 6.6, the stray root files: there is no evidence they break a user workflow or threaten pilot readiness, so they rank below the substantive product and operations gaps.
