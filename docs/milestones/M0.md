# M0. Project setup: what was built

Finished 2026-10-23. M1 (the billing engine) was built before the last M0 task, so both are now done. Next up is **M2: data, auth and setup screens**.

## In plain words

M0 is the foundation that everything else sits on. A landlord can't do anything useful with it yet. What's there:

- **The app itself**, with the menu landlords will use every day: **Today, Leases, Tenants, Billing, Reports**. On a phone the menu is a row of tabs at the bottom of the screen; on a laptop it's a sidebar on the left. **Settings** sits behind the profile icon, not in the main menu, because most people rarely need it.
- **Each page is a placeholder for now**: a heading and one sentence saying what will go there.
- **Indian formats** are built in, ready for every screen: ₹12,34,567 (lakh and crore grouping), dates as DD-MM-YYYY, and financial years running April to March.
- **A local database** (Supabase, running on the developer's computer through Docker) and the tools to change it safely. There are no tables yet; the first ones (organizations, buildings, tenants) come in M2.
- **A safety lock on the database scripts**: they refuse to touch any database that isn't on the developer's own computer unless someone deliberately allows it. A real customer database can't be changed by accident.
- **Automatic checks** that run before every change is saved: type checks, code style, unit tests and a browser test at phone and laptop widths.
- **Setup instructions** in `README.md`, and an `.env.example` file listing the secret keys the app will need later.

## How to try it

1. In a terminal in the project folder: `pnpm install`, then `pnpm dev`.
2. Open http://localhost:3000. You land on **Today**.
3. Tap each item in the menu: Today, Leases, Tenants, Billing, Reports. The current one is highlighted.
4. Tap the **profile icon** (top right of the screen) to open **Settings**.
5. Make the browser window narrow (or use your phone on the same Wi-Fi network) to see the bottom tabs replace the sidebar.

To see the database: start Docker Desktop, run `supabase start`, and open Studio at http://127.0.0.1:54323. It will be empty until M2.
